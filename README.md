# FurniturePlugin - AutoCAD 家具设计插件

## 概述

FurniturePlugin 是一个专为 AutoCAD 设计的家具设计插件，提供了丰富的板件建模、管理和分析功能。插件支持参数化建模、智能识别、批量处理等特性，大大提高了家具设计的效率。

## 主要功能

### 板件管理
- **SETI**: 设置板件信息
- **PLXG**: 批量修改板件信息
- **CKLB**: 查看板件列表
- **CZBJ**: 通过ID查找板件

### 参数化建模
- **CJBJ**: 快速创建板件
- **ZYCEBAN**: 左右侧板参数化建模
- **DINDIBAN**: 顶底板参数化建模
- **CENGBAN**: 层板参数化建模
- **BEIBAN**: 背板参数化建模
- **KJ**: 智能外框架创建 ⭐ 新功能

### 布尔运算
- **SUU**: 分别差集运算
- **BOO**: 智能内空识别与封闭

### 分析工具
- **OBB**: 计算有向包围盒尺寸

## 核心功能

### KJ - 智能外框架创建 ⭐ 新功能
**KJ** 命令是本插件的智能化建模功能，通过选择现有板件或框选区域自动识别尺寸，避免重复输入参数，大大提高参数化建模的效率。

#### 核心特点
- **智能尺寸识别** - 通过选择现有板件自动推算柜体尺寸
- **框选区域识别** - 框选包含板件的区域，自动分析框架尺寸
- **外框架优先** - 先创建参数化外框架，再根据框架创建内部板件
- **自动计算** - 根据盖法自动计算各板件的精确尺寸
- **参数继承** - 新板件自动继承框架的材质和厚度参数

#### 智能识别算法
- **板件特征分析**：根据长宽高比例自动判断板件类型（侧板/顶底板）
- **尺寸推算**：基于选中板件的尺寸和类型推算整体柜体尺寸
- **区域分析**：分析框选区域内所有板件的分布和尺寸关系
- **参数验证**：自动验证推算结果的合理性

#### 使用方法
1. 输入 `KJ` 命令打开智能外框架界面
2. 选择识别方式（选择板件/框选区域/手动输入）
3. 设置板件参数（厚度、材质、盖法）
4. 选择创建选项（左右侧板/顶底板）
5. 点击"创建框架"按钮在指定位置创建板件

#### 应用场景
- 基于现有板件快速创建配套板件
- 批量创建标准化柜体框架
- 复制现有柜体的尺寸规格
- 参数化建模的起始框架创建

### BOO - 智能内空识别与封闭 ⭐ 重点功能
**BOO** 命令是本插件的核心功能，能够智能识别由多条交叉线条围成的所有内空区域，并自动创建封闭边界或面域。该功能类似于 AutoCAD 的 BOUNDARY 命令，但专门针对复杂的交叉线条图形进行了优化。

#### 核心特点
- **精确边界追踪** - 使用先进的边界追踪算法，能够准确识别复杂的内空形状
- **凸包计算** - 采用 Graham 扫描算法计算区域的凸包，确保边界的准确性
- **洪水填充** - 使用洪水填充算法进行连通性分析，自动分离不同的内空区域
- **高密度采样** - 使用 100x100 网格进行高精度采样，提高识别准确性
- **多类型支持** - 支持直线、圆弧、圆、多段线等各种曲线类型
- **智能优化** - 自动优化边界形状，使其更贴合实际的线条轮廓

#### 技术实现
- **边界追踪算法**：使用网格采样结合射线法进行内外判断
- **凸包计算**：Graham 扫描算法确保边界的几何正确性
- **连通性分析**：洪水填充算法自动分离不同区域
- **射线相交检测**：精确计算射线与各种曲线类型的交点
- **角度范围检查**：准确处理圆弧的角度范围限制

#### 使用方法
1. 输入 `BOO` 命令
2. 选择要分析的线条对象
3. 选择创建类型（B=边界，R=面域）
4. 系统自动识别并创建所有内空边界

#### 支持对象类型
- Line（直线）
- Arc（圆弧）
- Circle（圆）
- Polyline（多段线）
- 混合线条组合

#### 应用场景
- 建筑设计中的房间空间识别
- 机械设计中的孔洞和空腔分析
- 平面布局的功能区域划分
- 工程制图的复杂边界创建

## 安装和使用

1. 将插件文件复制到 AutoCAD 插件目录
2. 在 AutoCAD 中使用 `NETLOAD` 命令加载插件
3. 输入相应的命令开始使用

## 系统要求

- AutoCAD 2021-2025
- .NET 8.0 或更高版本
- Windows 10/11
